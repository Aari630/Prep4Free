# **App Name**: Algo Ace

## Core Features:

- Problem Display: Display coding problems with descriptions and constraints.
- Code Editor: Provide a Monaco-powered code editor with syntax highlighting and autocompletion.
- Language Selection: Allow users to select programming languages for code submissions.
- Code Submission: Submit code to the Judge0 engine for execution and judging.
- Submission Status: Show submission status and results (accepted, wrong answer, etc.).
- User Authentication: Allow users to create accounts and log in securely.
- AI Assisted Refactoring Tool: Uses generative AI as a tool that suggest code refactoring options and improve code quality, maintainability, and readability by processing all project source files.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey professionalism and intellect.
- Background color: Light gray (#F5F5F5) for a clean and modern look.
- Accent color: Electric purple (#7E57C2) for highlighting interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif known for its modern, neutral look; appropriate for both headlines and body text.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use clean and simple icons from a library like FontAwesome or Material Icons.
- Employ a two-panel layout for problem descriptions and the code editor.
